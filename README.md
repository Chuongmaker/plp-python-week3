# Week 3 Assignment on Conditions and Loops

## Grade Reporter & Bug Hunt

This assignment practices Python conditions, `for` loops, `while` loops, counting, and running totals.

### Files

- `grade_reporter.py` - Loops through the scores, assigns grades, counts passes and failures, and calculates the average.
- `bug_hunt.py` - Finds and fixes three bugs in a program that calculates the sum of numbers from 1 to 5.

### Bug Hunt Reflection

The hardest bug to find was the incorrect `while` loop condition because it did not produce an error message. I knew something was wrong because the program produced the wrong answer instead of the expected total of 15. I fixed the condition so that the loop includes 5.
